Introduction

Vanta is a lightweight programming language written in C.

This documentation describes the syntax, built-in functions, runtime behavior and features available in this version.

Installation

Download the Vanta interpreter and place it somewhere on your system. 

vanta.exe hello.vt

Syntax

A simple Vanta program: 

print("Hello, world!")

Variables

Variables can be declared using let. 

let name = "Vanta"
let age = 1

print(name)
print(age)

Types

Vanta supports several fundamental value types.

  • Number
  • String
  • Boolean
  • List
  • Null

Operators

let a = 10
let b = 3

print(a + b)
print(a - b)
print(a * b)
print(a / b)

Control flow

if

if x > 10 {
    print("large")
} else {
    print("small")
}

while

let x = 0

while x < 10 {
    print(x)
    x = x + 1
}

for

for i = 0; i < 10; i = i + 1 {
    print(i)
}

Functions

fn greet(name) {
    print("Hello, " + name)
}

greet("Vanta")

Lists

let numbers = [1, 2, 3, 4]

print(numbers[0])

Exceptions

try {
    let x = 10 / 0
} catch {
    print("Something went wrong")
}

File I/O

file_write(
    "hello.txt",
    "Hello from Vanta!"
)

let text = file_read("hello.txt")

print(text)

vtUI

vtUI provides graphical user interface functionality for Vanta programs. 

import "vtUI"

window("My Vanta App", 800, 600)
